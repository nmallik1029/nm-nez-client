# screenshots

In-game screenshots for the settings library's Pro picks, one per pick, named
in that pick's `screenshot` in `../client.json`. See `../README.md`.

These do not ship with the client. A client fetches one from the repo the
first time someone opens that pick, so a new screenshot is live once it is on
`main`. To change one, give the new picture a new file name: a client keeps
the first copy of a name it fetched.
